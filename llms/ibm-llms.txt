# IBM Cloud Documentation

> Documentation for IBM Cloud services, platform capabilities, and developer tools

Each IBM Cloud Docs page URL in this file includes `?format=markdown` to return Markdown directly. You can also request `Markdown` for these URLs by sending `Accept: text/markdown` in the request header, for example `curl -H "Accept: text/markdown" "{docs-url}"`. Individual API reference pages support machine-readable access: sending `Accept: application/json` (or appending `.json` to the URL) returns the full OpenAPI spec for that service.

## Library pages

- [Home](https://cloud.ibm.com/docs): IBM Cloud documentation home page
- [API Reference Library](https://cloud.ibm.com/docs?tab=api-docs&format=markdown): Complete API reference for all IBM Cloud services. Implements RFC 9727: send `Accept: application/linkset+json` to receive a machine-readable catalog of all available API specs.
- [Tutorials Library](https://cloud.ibm.com/docs?tab=tutorials&format=markdown): Step-by-step tutorials and learning paths
- [FAQs Library](https://cloud.ibm.com/docs?tab=faqs&format=markdown): Frequently asked questions
- [Product Guides Library](https://cloud.ibm.com/docs?tab=all-docs&format=markdown): Documentation for all IBM Cloud products
- [Solution Docs Library](https://cloud.ibm.com/docs?tab=solutions&format=markdown): Architecture and solution documentation
