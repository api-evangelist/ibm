IBM has released Granite Libraries and Project Granite Switch, modular tools that apply software engineering principles to large language models. These offerings enable developers to compose specialized adapter functions for tasks like retrieval-augmented generation and safety checks without retraining entire models. The release includes three libraries (RAG, Core, and Guardian) designed to work with IBM's new Granite 4.1 foundation models, delivering more sustainable, enterprise-ready AI systems.
