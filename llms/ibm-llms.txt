# IBM

> A collection of IBM's public APIs and developer resources spanning IBM Cloud infrastructure, watsonx AI, data, and enterprise software. IBM authenticates every service API with IAM bearer (JWT) tokens minted from an API key, and ships generated SDKs across npm, PyPI, Maven, NuGet, RubyGems, and Go. This file was generated by API Evangelist from the catalog for IBM (developer.ibm.com); IBM does not publish its own llms.txt.

## APIs
- [IBM Cloud IAM Identity Services](https://cloud.ibm.com/apidocs/iam-identity-token-api): Manage IAM access tokens, API keys, service IDs, and trusted profiles.
- [IBM watsonx.ai](https://cloud.ibm.com/apidocs/watsonx-ai): Text inference, prompt tuning, and generative AI on foundation models.
- [IBM watsonx.data](https://cloud.ibm.com/apidocs/watsonxdata-software): Unified data lakehouse for structured and unstructured enterprise data.
- [IBM watsonx.governance](https://cloud.ibm.com/apidocs/ai-openscale): Monitor, govern, and manage AI models.
- [IBM Watson Assistant](https://cloud.ibm.com/apidocs/assistant/assistant-v2): Build conversational interfaces into any application or channel.
- [IBM Watson Discovery](https://cloud.ibm.com/apidocs/discovery-data): Cognitive search and content analytics over unstructured data.
- [IBM Cloud Object Storage](https://cloud.ibm.com/docs/cloud-object-storage/api-reference): S3-compatible object storage.
- [IBM Cloud Kubernetes Service](https://cloud.ibm.com/apidocs/kubernetes): Managed Kubernetes cluster infrastructure.
- [IBM Cloud Code Engine](https://cloud.ibm.com/apidocs/codeengine): Serverless containerized workloads.
- [IBM API Connect](https://cloud.ibm.com/apidocs/apiconnect/apic-management-api): End-to-end API management.
- [IBM Cloudant](https://cloud.ibm.com/apidocs/cloudant): Managed distributed JSON document database.
- [IBM Event Streams](https://cloud.ibm.com/apidocs/event-streams/adminrest): Managed Apache Kafka.
